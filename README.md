# The Best Meal You Ever Had

A program that writes one sentence — 159 characters — about the best meal
the entrant ever had, to `/output/entry.txt`.

> The best meal I ever had was a cold rice ball my mother packed for a school
> trip, eaten on a bus, and it tasted like the whole morning she had woken
> early for.

Run it with Node 22: `node main.ts`. It writes `entry.txt` to
`$MAKEFUN_OUTPUT_DIR` (or `./output`), exits 0, uses no network.
